**original_problem_statement:** The user wants to add a major new feature to the existing multi-tenant route sales management app: a complete **Customer Ordering System**. This will transform the app into a two-sided ecosystem where distribution companies manage their operations and their customers can place orders directly through the app.

This new system must support multiple distribution companies, allow customers to register and choose which company to order from, generate unique order numbers, provide order confirmation and sharing (via WhatsApp), and handle delivery day schedules. Future requirements include order adjustments by the distributor, customer notifications, and an order cut-off system to ensure operational efficiency.

**PRODUCT REQUIREMENTS:**
1.  **Dual User Ecosystem:**
    *   **Distributors:** Manage products, routes, customers, and drivers. Receive and manage incoming customer orders.
    *   **Customers:** A new user type with a simplified interface to view products from specific distributors, place orders, and track order status.
2.  **Multi-Tenancy & Marketplace:**
    *   Customers must be able to register and select which distribution company they want to order from.
    *   A customer should be able to order from multiple different companies on the platform.
    *   Data must remain strictly isolated: companies only see their own customers, orders, and products.
3.  **Customer Ordering Flow:**
    *   A simple UI for customers to select a company, browse their products, add items to a cart, and submit an order.
    *   The system must generate a unique, trackable order number (e.g., ).
4.  **Order Confirmation & Sharing:**
    *   After placing an order, the customer must see a confirmation screen with the order number and status.
    *   Customers must be able to share their order confirmation via a native Share sheet (specifically for WhatsApp, SMS, Email).
5.  **Delivery & Order Management:**
    *   Distributors must be able to assign delivery days to their routes. The app should inform the customer of their next delivery day.
    *   Distributors need a dashboard to view and manage incoming orders (confirm, adjust for stock).
    *   Drivers should see orders assigned to their specific route.
6.  **Order Cut-Off System (Future Phase):**
    *   Distributors must be able to set an order cut-off time for each route (e.g., order by Monday 4 PM for Tuesday delivery).
    *   The system should prevent late orders and notify customers of the next available delivery slot.
    *   The system should include reminder notifications and a visual countdown timer for customers.
